File format

A header row is detected automatically — name, email, phone, an optional region and an optional grade (matched by name — e.g. {{ ", ".join([g.name for g in grade_cohorts_all]) }}). Without a header, columns are read in that order. A phone number is required for every row since it's used to generate the password; rows missing one, with an invalid email/phone or grade cohort, or matching an existing account are skipped.
