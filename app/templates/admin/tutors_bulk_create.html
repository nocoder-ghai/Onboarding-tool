Bulk-create tutor logins

Upload a sheet of name, email, phone, region, grade cohort and DB ID. Each row becomes a tutor account with a generated password (Cue@ plus their phone number) — copy these out to share with each tutor, they're shown only once. Region and grade cohort together decide which training each tutor sees. DB ID is the unique code that identifies the coach and their journey across systems (e.g. the Rise training data) — optional, but must be unique per tutor if given.

File format

A header row is detected automatically — name, email, phone, an optional region, an optional grade (matched by name — e.g. {{ ", ".join([g.name for g in grade_cohorts_all]) }}) and an optional db id. Without a header, columns are read in that order. A phone number is required for every row since it's used to generate the password; rows missing one, with an invalid email/phone or grade cohort, or matching an existing account (by email, phone, or a DB ID already assigned to someone else) are skipped.
