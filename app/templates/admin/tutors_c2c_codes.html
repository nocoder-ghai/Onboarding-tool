File format

Two columns: the tutor, then their C2C code. A header row is detected automatically; without one, columns are read in that order. The tutor is matched on email, phone or DB ID — whichever you have. A code already held by another coach is skipped, and so is anything that matches nobody — both are listed back to you, so a partial file is safe to upload. Uploading a new code for a coach replaces their old one.
