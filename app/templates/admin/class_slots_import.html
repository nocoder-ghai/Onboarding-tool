File format

A header row is detected automatically. Expected columns are student name, class date, class time and grade. Times can be written as 14:30 or 2:30 PM. You can optionally add duration (minutes, defaults to 60), region, grade group and notes columns too. Every row becomes an open slot — no tutor assigned yet — for a tutor to pick from Class with a Student.

Dates are read month first

3/9/2026 is 9 March, not 3 September — the month/date/year order a spreadsheet exports. 2026-03-09 and 9 Mar 2026 are read the same way and leave no room for doubt, so prefer one of those if you are ever unsure.

grade group restricts a slot to coaches licensed for it — K-5, 3-8 or 9-12. Leave it out and any coach can take the class. A row naming a group that doesn't exist is skipped rather than imported unrestricted.
