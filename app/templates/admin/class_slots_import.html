File format

A header row is detected automatically. Expected columns are student name, class date, class time and grade. Dates can be written as 2026-09-15, 15/09/2026 or 15 Sep 2026; times as 14:30 or 2:30 PM. You can optionally add duration (minutes, defaults to 60), region and notes columns too. Every row becomes an open slot — no tutor assigned yet — for a tutor to pick from Class with a Student.
