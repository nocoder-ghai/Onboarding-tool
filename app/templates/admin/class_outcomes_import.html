File format

The first row must hold the headers. Each coach is matched on their Teacher DBID; Teacher Name is for your reference only. Class Done is optional — leave it out and every row is marked done. Write Yes or Done for a class that happened, No or Didn't happen for one that didn't (that coach can then book another).

A coach with a booked class has that class marked. A coach marked Yes with no booked class — one arranged outside the tool — still gets the step marked done. Rows that match nobody, or are already done, are listed back to you, so a partial sheet is safe to upload.
